# Günlük İlerleme Raporu

**1. Gün (8 Haziran):**
* Vite ile projenin temel altyapısını kurdum.
* SCSS klasör yapısını oluşturdum ve temel tasarım değişkenlerini (renk, font) ayarladım.
* Sayfanın HTML iskeletini hazırladım.

**2. Gün (9 Haziran):**
* İstenen UI bileşenlerini (Button, Card, Accordion, Modal, Form) ayrı ayrı kodladım.
* Bileşenleri ana sayfada birleştirip tüm yapıyı mobil uyumlu (responsive) hale getirdim.
* JavaScript ile Light/Dark tema geçişini ve form uyarılarını ekledim.
* Lighthouse testini yapıp performansı kontrol ettim.

**3. Gün (10 Haziran):**
* Projeyi Vercel üzerinden canlı yayına aldım.
* README ve CHANGELOG dosyalarını güncelledim.
* Son kontrolleri yapıp projeyi teslimata hazır hale getirdim.
